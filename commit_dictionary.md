# Commit Dictionary

| Type         | Meaning                                        | Example                                       |
| ------------ | ---------------------------------------------- | --------------------------------------------- |
| **feat**     | A **new feature** added to the project         | `feat: add knowledge graph extractor`         |
| **fix**      | **Bug fix**                                    | `fix: resolve crash in parser`                |
| **docs**     | Changes to **documentation only**              | `docs: update README with setup instructions` |
| **style**    | Formatting changes (no code logic change)      | `style: fix indentation in training script`   |
| **refactor** | Code restructuring without changing behavior   | `refactor: simplify graph construction logic` |
| **perf**     | Performance improvements                       | `perf: optimize graph traversal algorithm`    |
| **test**     | Adding or modifying tests                      | `test: add unit tests for entity extraction`  |
| **build**    | Changes affecting build system or dependencies | `build: update pytorch dependency`            |
| **ci**       | Changes to CI/CD pipelines                     | `ci: update github actions workflow`          |
| **chore**    | Maintenance tasks not affecting source code    | `chore: update .gitignore`                    |
| **revert**   | Reverting a previous commit                    | `revert: revert incorrect tokenizer update`   |
